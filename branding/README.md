# roadie.fm branding

The logo is a guitar pick with a star cut out of it. Everything here is generated by `generate.py` (needs only Pillow):

```bash
python3 branding/generate.py
```

## Colours

| Token | Hex | Use |
|---|---|---|
| Amber (light) | `#d9821a` | Mark and `.fm` on light backgrounds |
| Amber (dark) | `#f2ad45` | Mark and `.fm` on dark backgrounds |
| Ink (light) | `#1c1d21` | Wordmark text on light |
| Ink (dark) | `#f1efe9` | Wordmark text on dark |
| Plate | `#17181c` | App icon background |

## Files

| File | Use |
|---|---|
| `roadie-mark.svg` / `roadie-mark-dark.svg` | Mark for light / dark backgrounds |
| `roadie-mark-mono.svg` | Single colour (`currentColor`), e.g. inline in the React UI |
| `favicon.svg` | Browser tab; switches amber shade with `prefers-color-scheme` |
| `favicon.ico` | 16/32/48 px fallback favicon |
| `roadie-lockup-light.svg` / `-dark.svg` | Mark + "roadie.fm" wordmark (live text in Bricolage Grotesque 700; outline before using where the font isn't loaded) |
| `icons/icon-192.png`, `icons/icon-512.png` | PWA manifest icons (`purpose: any`) |
| `icons/icon-maskable-512.png` | PWA maskable icon (mark inside the safe zone) |
| `icons/apple-touch-icon.png` | iOS home screen (180 px, opaque) |
| `icons/mark-512.png` | Transparent PNG of the mark |

The star is cut out with `fill-rule="evenodd"`, so the background always shows through it.

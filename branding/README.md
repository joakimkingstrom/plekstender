# Plekstender branding

The logo is a solid guitar pick (black on light, white on dark) holding a half-filled amber star, a nod to half-star ratings. Everything here is generated by `generate.py` (needs only Pillow):

```bash
python3 branding/generate.py
```

## Colours

| Token | Hex | Use |
|---|---|---|
| Ink (light) | `#1c1d21` | Pick and wordmark on light backgrounds |
| Ink (dark) | `#f1efe9` | Pick and wordmark on dark backgrounds |
| Amber (bright) | `#f2ad45` | Star on the black pick |
| Amber (deep) | `#d9821a` | Star on the white pick |
| Plate | `#17181c` | App icon and GIF background |

The star always uses the amber that contrasts with the pick under it, so the shades swap with the pick colour.

## Files

| File | Use |
|---|---|
| `plekstender-mark.svg` / `plekstender-mark-dark.svg` | Mark for light / dark backgrounds |
| `plekstender-mark-mono.svg` | Single colour (`currentColor`), star cut through the pick; e.g. inline in the React UI |
| `favicon.svg` | Browser tab; switches pick and star colours with `prefers-color-scheme` |
| `favicon.ico` | 16/32/48 px fallback favicon: white pick on a rounded dark tile, so it shows on light and dark tabs |
| `plekstender-lockup-light.svg` / `-dark.svg` | Mark + "plekstender" wordmark (live text in Bricolage Grotesque 700; outline before using where the font isn't loaded) |
| `icons/icon-192.png`, `icons/icon-512.png` | PWA manifest icons (`purpose: any`): white pick on the dark plate |
| `icons/icon-maskable-512.png` | PWA maskable icon (mark inside the safe zone) |
| `icons/apple-touch-icon.png` | iOS home screen (180 px, opaque) |
| `icons/mark-512.png` / `icons/mark-dark-512.png` | Transparent PNG of the mark for light / dark backgrounds |

At 16 px the half-fill on the star doesn't read; the pick shape carries the mark at that size.

## Loading animation

The pick strums: it rocks ±10° from near its top, and the half-filled star turns one point on each stroke (1.2 s loop).

| File | Use |
|---|---|
| `plekstender-loader.svg` | Animated SVG (SMIL) for the web app; switches colours with `prefers-color-scheme`. Works in `<img>` and inline. |
| `loader-light-{128,256}.gif` | Black pick on white, for places that need a GIF |
| `loader-dark-{128,256}.gif` | White pick on the dark plate (`#17181c`) |

GIFs have a solid background because GIF transparency is 1-bit and leaves jagged edges.

### Spinning variant

The pick spins in 3D around a vertical axis through its tip, like a coin spun on its edge: the tip stays put while the shoulders swing round. One full turn per loop (1.6 s), pausing briefly face-on; on the back face the half-filled star shows mirrored. The SVG fakes the 3D turn with a sampled horizontal scale, since SMIL has no 3D rotation.

| File | Use |
|---|---|
| `plekstender-loader-spin.svg` | Animated SVG, theme-aware like the strum loader |
| `loader-spin-light-{128,256}.gif` | GIF on white |
| `loader-spin-dark-{128,256}.gif` | GIF on the dark plate |

## GitHub

| File | Use |
|---|---|
| `github/social-preview.png` | Repository social preview (1280 × 640): the card shown when the repo is linked on social media or chat |
| `github/readme-header-light.png` / `-dark.png` | Logo with the name at the top of the main README; GitHub picks the one matching the reader's theme |

These set the wordmark in Bricolage Grotesque from the frontend's `@fontsource` package, so run `npm install` in `frontend/` before `generate.py` (it skips them otherwise).

The social preview can't be set from the repo itself: upload `github/social-preview.png` under the repository's **Settings → General → Social preview → Edit → Upload an image**.
